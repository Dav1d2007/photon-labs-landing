# Photon Labs — Landing page estática

Sitio informativo de una sola página para presentar la solución propuesta a la situación-problema de TE1020.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub, por ejemplo `photon-labs-landing`.
2. Sube `index.html`, `README.md` y la carpeta `assets/` conservando su estructura.
3. En el repositorio abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que GitHub Pages publique el sitio. La URL aparecerá en esa misma sección.

El sitio es estático: no contiene calculadora, formularios, base de datos ni generación real de PDF. Presenta la metodología y el alcance de la solución. Los cálculos y cifras del caso escolar deberán completarse con datos medidos, fichas técnicas y precios verificables.
